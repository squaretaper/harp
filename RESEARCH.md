# HARP research notes

This page is informative and intentionally short.

The earlier research report in this repository was written around the retired `.harp.md`/epoch/IPFS prototype. It made architecture and novelty claims that are not part of the current v0.1 wire contract, so it has been removed from the active documentation rather than silently presented as current research.

For the current system boundaries and adjacent protocol categories, see [ECOSYSTEM.md](ECOSYSTEM.md).

For the normative contract, see:

- [HARP v0.1 schemas and fixtures](protocol/harp/v0.1/README.md)
- [Protocol specification](SPEC.md)
- [Architecture and rationale](DESIGN.md)
- [Migration from the prototype](MIGRATION.md)

The historical report remains available through Git history and the historical `v0.1.0` tag. Statements in that report—especially claims about mandatory IPFS/onchain storage, human principals, public/shared/private files, standard trust scores, or uniqueness—must not be attributed to current HARP v0.1 without fresh evidence.
